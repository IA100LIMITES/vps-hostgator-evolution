# Instalador da Evolution API para a VPS HostGator

Para a VPS da HostGator criada com **Aplicação → n8n**. Entre no console como `root` e rode:

```bash
curl -fLo v vps.iasemlimites.com
bash v
```

No fim aparecem o endereço do n8n, o painel da Evolution, a chave da API e os dados do Postgres para a credencial do n8n.
Para ver esses dados de novo: `dados`
